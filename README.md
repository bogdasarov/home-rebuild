# Ремонт на Дзержинце

Справочник по ремонту двухкомнатной квартиры 43,6 м² в панельном доме серии 1-464
(Пушкино, Дзержинец, 1976 г., 5-й этаж из 9, санузел раздельный, газовая плита).

**Онлайн:** https://bogdasarov.github.io/home-rebuild/

## Что внутри

Один самодостаточный `index.html` — ни сборки, ни зависимостей, ни бэкенда.
Из внешнего только Google Fonts (Golos Text, PT Serif, JetBrains Mono).

15 разделов: объект и конструктив 1-464, порядок работ, решения до старта,
демонтаж, электрика, освещение, сантехника, санузел, кухня и газ, вентиляция
и окна, черновые работы, чистовая отделка, скрытые работы, деньги, расчёты.

## Интерактив

- **Поиск** по всему справочнику — фильтрует разделы по мере ввода.
- **Мои решения** — поля в конце разделов, сохраняются в `localStorage` браузера.
- **Выгрузить / Загрузить** — экспорт и импорт этих полей в JSON-файл.
- **Печать** — отдельные стили: навигация и поля ввода скрываются.
- **Тёмная тема** — следует настройке операционной системы.

Личные заметки никуда не отправляются: они живут только в браузере на том
устройстве, где вы их вводили. Поэтому на новом устройстве их не будет —
переносите файлом через «Выгрузить» / «Загрузить».

## Задачи

Бэклог ведётся в [Issues](https://github.com/bogdasarov/home-rebuild/issues).
Метки: приоритет (высокий / средний / низкий) и область — содержание,
интерфейс, данные, нормативы, после ремонта.

## Как править

```bash
git clone git@github.com:bogdasarov/home-rebuild.git
cd home-rebuild
open index.html          # правки видны по обновлению страницы
git commit -am "…" && git push   # публикация занимает ~1 минуту
```

Структура файла: `<head>` — токены темы и все стили; `<body>` — шапка,
боковая навигация `nav.side`, затем `<section id="…">` по одной на раздел;
в самом низу один `<script>` с поиском, сохранением и калькуляторами.

Добавляя раздел, нужно сделать два изменения: `<li><a href="#новый-id">`
в `nav.side` и сам `<section id="новый-id">` в `<main>`.

Классы блоков-врезок: `.b.no` — запреты, `.b.house` — про дом,
`.b.care` — предостережения, `.b.money` — деньги, `.b.check` — проверить.
