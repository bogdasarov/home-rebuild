# Справочник «Ремонт на Дзержинце»

Один самодостаточный `index.html` (~139 КБ), публикуемый на GitHub Pages:
https://bogdasarov.github.io/home-rebuild/

Происхождение: артефакт Claude
`https://claude.ai/code/artifact/57e056e9-5b6f-4465-a68e-a1687281e0ef`.
Артефакт больше не источник правды — правки вносятся здесь, обратно не
синхронизируются.

## Объект, о котором справочник

Пушкино, Дзержинец. Панельный дом серии 1-464, 1976 г., 5-й этаж из 9.
43,6 м², две комнаты, санузел раздельный, газовая плита. Квартира мамы.
Ключевые ограничения объекта: поперечные несущие панели, двухпроводная
сеть без защитного проводника, ограниченная выделенная мощность (3–5 кВт),
возможная сантехкабина, полы по лагам с засыпкой.

## Правила работы с файлом

- **Никакой сборки и зависимостей.** Всё inline. Из внешнего только Google
  Fonts. Не добавлять npm, бандлеры, CDN-библиотеки и фреймворки: файл должен
  открываться двойным кликом с диска и работать без сети (кроме шрифтов).
- **Разметка файла:** `<head>` — CSS-токены темы и все стили; `<body>` —
  `header.top`, `nav.side` со списком разделов, `main` с `<section id="…">`,
  внизу один `<script>` (поиск, автосохранение, экспорт/импорт, калькуляторы).
- **Новый раздел = два изменения:** пункт `<li><a href="#id">` в `nav.side`
  и `<section id="id">` в `main`. Порядок в навигации повторяет порядок секций.
- **Темизация только через переменные** `--bg`, `--ink`, `--accent` и т.д.
  Они объявлены трижды: `:root`, `@media (prefers-color-scheme: dark)` под
  `:root:not([data-theme="light"])` и `:root[data-theme="dark"]`. Хардкод цветов
  ломает тёмную тему.
- **Врезки:** `.b.no` — запреты, `.b.house` — про конструктив дома,
  `.b.care` — предостережения, `.b.money` — деньги, `.b.check` — что проверить.
  Поля пользователя — блок `.mine` с `data-k="уникальный-ключ"`; ключ участвует
  в localStorage и в JSON-экспорте, менять его у существующего поля нельзя —
  потеряются уже введённые данные.
- **Таблицы** оборачивать в `<div class="tw">`, числовые колонки — `class="n"`.
- Проверять, что печать не сломалась: в `@media print` скрыты навигация,
  шапка и калькуляторы.

## Публикация

`git push` в `main` — Pages подхватывает корень репозитория, публикация
занимает около минуты. Файл `.nojekyll` отключает обработку Jekyll.
